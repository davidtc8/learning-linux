## WHy?
You're probably wondering why the hell did I change to Ubuntu. Well, that's because I'm trying to get better at DevOps, that's usually what I've been dedicating for the last 2 years. 

However, I have had my downfalls and I have noticed some areas where I could definitively improve. 

So while researching the deep web, I found out a nice link to a **[reddit](https://www.reddit.com/r/devops/comments/1tm5yta/how_should_i_start_learning_devops_as_an_absolute/)** post about how to start DevOps from scratch.

![image](https://media2.giphy.com/media/v1.Y2lkPTc5MGI3NjExM3ZucmQ2b3F5ZXdsd3NnajV2MGI3MThtczkzcWxkb2RqOWN4NWZnbCZlcD12MV9pbnRlcm5hbF9naWZfYnlfaWQmY3Q9Zw/m2Q7FEc0bEr4I/giphy.gif)

So right now, I'm following this:

Linux (2 weeks) -> Docker (2 weeks) -> Kubernetes (1 month) -> AWS -> CI/CD Pipeline -> Monitoring/Observability Tool

In a nutshell, that's why I started with Linux. 

However, for my fellow recruiters, this is not my first time working with these technologies, because I have 2 years of experience working with these (except for Linux), however, right now, I want to take a deep dive into the basics, so when I get to the "complicated" things, they'll become clearer.

Having said this, let's get to work, there's much to do.
